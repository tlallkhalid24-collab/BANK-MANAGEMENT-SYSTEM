# BANK-MANAGEMENT-SYSTEM
Developed using C++ programming language
Console/command-line based application
Used to manage basic banking operations digitally
Implements Object-Oriented Programming (OOP) concepts
Provides a simple and user-friendly menu-driven interface
Stores customer records using file handling
Allows creation of new bank accounts
Supports money deposit and withdrawal operations
Provides balance inquiry feature
Enables account searching and record management
Reduces manual paperwork and human errors
Improves speed, accuracy, and efficiency of banking tasks
Uses concepts like:
Classes and Objects
Encapsulation
Inheritance
Polymorphism
Abstraction
Helps in learning real-world software development
Suitable for educational and academic purposes
Can be upgraded with:
GUI
Database integration
Login system
Online banking features
